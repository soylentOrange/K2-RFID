Firmware

Reserves the memory for Update Database at boot, so the download can't fail with "Not enough memory".

Install

  1. Connect the board with a USB cable.
  2. Hold the 0 button, press and release RST, then release 0 (download mode).
  3. Click Install, pick the serial port of the board and install.
  4. Press the RST button on the board when it's done: the S2 can't be reset over USB, the reset in the installer has no effect.
  5. WiFi: click Install again and pick the port (it has a new name now), then choose Connect to Wi-Fi (from v1.4.2-beta on). Or connect to the WiFi K2RFID and set it up there.

Your browser can't access serial ports. Use Chrome or Edge on a desktop computer.

Installing needs a secure (https) connection.

The factory image contains everything (bootloader, SafeBoot, firmware, file system) and replaces the WiFi settings and the material database on the board. It's meant for the first installation; later updates go over WiFi via SafeBoot (Settings > SafeBoot) with the .firmware.bin of the release.
